# Отложенная задача: автоматическое резервное копирование базы

Статус: отложено по решению пользователя.

Нужно выбрать постоянное внешнее хранилище и реализовать автоматическое резервное копирование PostgreSQL. Рассмотреть варианты: встроенные резервные копии Render PostgreSQL, S3-совместимое хранилище или Google Drive через отдельный постоянно авторизованный процесс.

Требования:

- не использовать локальный диск Render как единственное хранилище;
- сохранять данные Oracle Studio, включая интерпретации Врат Золушки;
- предусмотреть восстановление и проверку целостности backup;
- сохранить ручной экспорт/импорт Oracle Studio как переносимый резервный вариант;
- после выбора хранилища добавить расписание и инструкцию восстановления.

До реализации backup ручные данные, внесённые через Oracle Studio, хранятся в PostgreSQL и должны отдельно экспортироваться в JSON перед миграцией проекта.

Дата фиксации: 2026-08-14.

Источник задачи: пользовательский запрос в проекте Aether Oracle.
