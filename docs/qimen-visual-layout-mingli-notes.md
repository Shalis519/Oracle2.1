# Параметры визуала личной карты Ци Мэнь

## Эталон Mingli

По предоставленным скриншотам и доступному просмотру карты зафиксированы следующие требования: внутренняя карта имеет квадратную геометрию 3×3; все девять дворцов имеют одинаковую ширину и высоту; элементы внутри дворца выстроены вертикально и не пересекаются; китайский символ располагается над русской подписью; центральный дворец является отдельным информационным блоком; направления и стихии размещаются вне периметра внутренней карты.

## Исправление терминологии

Текущее пользовательское название «Небесный Навес» для звезды 天蓬 неудачно для интерфейса. В русской версии используем транслитерацию **«Небесный Пэн»**, чтобы не выдавать буквальный перевод за устоявшееся имя звезды. Остальные названия сохраняются в формате китайский символ сверху, русская подпись снизу.

## Реализационные параметры

Внутренняя сетка должна иметь `aspect-ratio: 1 / 1`. Внешние подписи не должны участвовать в расчёте ширины ячеек. Для каждого элемента используется отдельный вертикальный блок с фиксированной высотой строки, уменьшенным шрифтом русской подписи и переносом длинных названий. Расчёты карты и выделение «Дворец Судьбы» не меняются.
