# Проверка источника координат tvoibazi.ru

Дата проверки: 2026-08-22.

Запрос к `https://tvoibazi.ru/wp-content/themes/invert/formapi3.php` с `search_city=Тараз` вернул запись:

- `id`: `1516905`
- `name`: `Тараз, Zhambylskaya Oblast’, Казахстан`
- `longitude`: `71.3666700`
- `latitude`: `42.9000000`
- `timezone`: `+6`
- `utc`: `UTC+06:00`

HTML оригинального калькулятора показывает, что после поиска города сайт записывает `json.lat`, `json.lng`, `json.timezone` и `json.resultOffset` в скрытые поля `cityX`, `cityY`, `cityUTC`. В ответе также используются поля `id`, `admin_id`, `alternatename`, что указывает на справочник городов с географическими идентификаторами; точный внешний провайдер по этой странице не назван.

Для точного воспроизведения tvoibazi.ru можно использовать `lat=42.9`, `lng=71.36667`, `utcOffset=6`. Однако рабочий стандарт Aether Oracle остаётся отдельным: проект использует локальную GeoNames-запись Тараза `lat=42.898`, `lng=71.3733`, timezone `Asia/Almaty`. Разницу примерно в одну минуту между калькуляторами принимаем как допустимое следствие разных координат и округления.

## Статус для Aether Oracle

Этот документ сохраняет результаты сравнительного исследования и не задаёт рабочие координаты проекта. В Aether Oracle используются координаты локального справочника GeoNames; координаты tvoibazi.ru применяются только для контрольного сравнения.
