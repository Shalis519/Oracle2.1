## Вывод

Ни один из этих семи репозиториев не является библиотечным каталогом, где можно подтвердить наличие Qi Men Dun Jia Compendium или других книг Joey Yap. Это программные проекты для организации, загрузки или публикации пользовательских библиотек. Их лицензии относятся к коду и не дают права на книги, которые пользователь может разместить внутри своей библиотеки.

Наиболее полезные для технической стороны Aether Oracle — `biblioverse/biblioteca`, `BookHeaven/BookHeaven.Server`, `bookstairs/bookstairs` и `oxdef/lib2opds`, если когда-либо понадобится изучить OPDS или управление документами. Для поиска источников по Ци Мэнь они не дают содержательных материалов.

Отдельно найденные ранее репозитории с многочисленными TXT-файлами (`gelaskaku` и похожие) относятся к другой категории и не должны смешиваться с этим списком: у них иная структура и отсутствуют подтверждённые лицензии на книжные материалы.
