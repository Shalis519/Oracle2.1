# Проверка доступа к Joey Yap Qimen Explorer

Дата проверки: 21.08.2026.

## Результат

Запрос к `https://qimenx.joeyyap.com/Personal/PlotChart` перенаправляет на `https://qimenx.joeyyap.com/Account/Login`. Страница сообщает: `Login To Access The Full Features of Qimen Explorer` и показывает форму Username/Email + Password.

При первом открытии дополнительно отображалось сообщение `Your session has expired. Please login again`. Это означает, что текущая браузерная сессия не авторизована или прежний cookie/session-token истёк. Это не ошибка расчёта карты.

## Что доступно без входа

На странице входа можно открыть публичные модальные окна Current Hour Chart и Current Day Chart. Текущая часовая карта действительно загрузилась и показала изображение карты, ствол часа и ствол дня. Полный раздел Personal/PlotChart без входа недоступен.

## Регистрация и восстановление

Ссылка Create Free Account ведёт на `https://register.joeyyap.com/?product=qimenx`. Текстовый ответ страницы регистрации указывает на отдельную регистрацию/подтверждение email. Ссылка Forgot Password ведёт на форму восстановления по email.

## Вывод

Причина невозможности войти в персональный калькулятор: он закрыт за авторизацией, а текущей действующей сессии нет. Без пользовательских email и пароля войти нельзя. Публичные текущие карты доступны, но они не заменяют персональный PlotChart.
