## Промежуточный вывод

Локальный код на каждой часовой карте находит только один кандидат с небесным стволом 丁 и звездой 天辅, затем применяет полный набор ограничений активации. Infengi возвращает пять часовых результатов: 卯, 巳, 申, 戌 и 亥. Поэтому результаты нельзя пока сравнивать как одну и ту же операцию: вероятно, infengi сначала выделяет структуру «Три Генерала допущены в главный зал», а ограничения «не активировать Врата на запрещённом направлении», Фу Инь, Пустота, Могила и Контроль Врат используются отдельным уровнем оценки активации.

Следующий безопасный шаг: разделить в нашем коде диагностику на два слоя: `rawThreeGenerals` для совпадения структуры с infengi и `activationEligible` для итогового разрешения активации по PDF. До такого разделения менять формулу нельзя.

Уточнение по generals.pdf.

Файл прямо задаёт состав структуры: один из Трёх Чудесных стволов 乙, 丙, 丁 плюс одна из трёх звёзд 天辅, 天心, 天任 плюс только Врата Отдыха, Жизни или Открытия.

Правила активации: используется только небесное кольцо; избегаются сектора Могилы; не активируются Врата Отдыха на Юге, Врата Жизни на Севере и Врата Открытия на Востоке; Врата не должны контролировать звезду; исключаются дворцы Пустоты; используются только часовые структуры; исключаются Гэн и Фу Инь; используется нормальный час по общему выбору; Дерево Ян осторожно с ЮЗ; Огонь Ян избегает Севера; Огонь Инь избегает СЗ и ЮЗ.

Отдельно в файле есть примечание: если после активации не увидеть подтверждающие знаки в течение нескольких часов, это означает, что активация генералов не произошла.

Таблицы страниц 1–2 задают результаты для каждого Чудесного ствола и направления. Для 丙 на Севере прямо указано «обычно плохая активация»; для 丁 на Севере указано «обычно плохая активация». Эти направления не должны публиковаться, даже если базовая комбинация ствола, звезды и Врат формально совпала.
