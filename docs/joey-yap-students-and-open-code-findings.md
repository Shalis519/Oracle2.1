# Joey Yap: ученики, официальная экосистема и открытый код

## Интервью

Видео пользователя: https://youtu.be/1EazhnesxUs?si=o8sDWvVelMDWrais

По анализу интервью Joey Yap описывает Ци Мэнь как инструмент стратегического принятия решений: вопрос → интерпретация карты → выбор курса действий. В видео он подчёркивает связь с И-Цзин, Пятью Элементами и Восьмью Триграммами, а также допускает использование ИИ для обработки больших массивов интерпретаций, оставляя решение человеку. Технических формул Zhi Run, годовых карт, расположения 直符/直使 или точного построения тарелок в интервью не найдено.

## BigFishMarquis Qimen

Репозиторий: https://github.com/perfhelf/bigfishmarquis-qimen

MIT, TypeScript. Заявлены четыре слоя: год, месяц, день, час; три метода часового Ju: Chai Bu, Mao Shan и Zhi Run. README указывает отдельные engines `zhirun.ts`, `shijia.ts`, `nianjia.ts`, `yuejia.ts`, `rijia.ts`, а также разделение shared-логики, данных и интерпретаций. Это очень полезная архитектурная ссылка для Aether.

Реализация `zhirun.ts` использует: поиск предыдущего 上元符头 среди 甲子, 己卯, 甲午, 己酉; расчёт 超神; расширение до 30 дней при 超神 > 9 на 芒种/大雪; проверку продолжения闰-периода в начале следующего термина; затем выбор 三元 и таблицы Ju. README заявляет 500+ тестовых образцов за 300 лет, но это заявление нужно подтверждать исходными тестами.

## qmenpowers

Репозиторий: https://github.com/skyfiredao/qmenpowers

GPL-3.0, чистый Bash, данные отделены от кода. README прямо заявляет реализацию только Zhi Run, часовой Shi Jia и вращающуюся тарелку. В `tools/data` находятся `jieqi_table.dat`, `ju_map.dat`, таблицы Врат, Звёзд, Духов, Луошу и правил. В `qimen_engine.sh` видны отдельные функции календаря, солнечных терминов, определения Ju, земной тарелки, 直符/直使, небесной и человеческой тарелок.

Его алгоритм Ju также ищет 上元符头, использует 超神, включает 30-дневное окно для 芒种/大雪 и проверяет продолжение предыдущего闰-периода. Это делает qmenpowers вторым интересным независимым кандидатом для тестов Zhi Run, хотя корректность его результата ещё нужно сравнить с контрольными картами Mingli/Infengi.

## Предварительный вывод

Для понимания Joey Yap наиболее ценны официальная страница The Tribe, QiMen Club, Qimen Explorer и открытые видео самого Joey. Публичные ученики и консультанты дают материал для интерпретаций и сравнения школ, но не заменяют техническую документацию.

Для кода наиболее перспективен BigFishMarquis: четыре слоя и три метода Ju, отдельный `zhirun.ts`, а также архитектурное разделение engines и data. Для Zhi Run особенно перспективен qmenpowers, поскольку его README и ядро явно отделяют Zhi Run от Chai Bu и формализуют этапы вычисления.
