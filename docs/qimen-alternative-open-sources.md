# Альтернативные открытые источники по Ци Мэнь Дунь Цзя

## Критерии

Источники разделены по назначению: вычислительные алгоритмы, первичные и библиографические материалы, интерпретации, академический контекст и контрольные калькуляторы. Ни один авторский сайт или открытый репозиторий не следует автоматически считать эталоном расчёта.

## Приоритет для Aether Oracle

Для исправления построения карт приоритет следует отдавать источникам в следующем порядке: книга пользователя и подтверждённые скриншоты эталонных карт; официальный калькулятор Joey Yap для соответствующей методики; несколько независимых реализаций с открытым кодом; Infengi и Navigator для эмпирического сравнения; авторские интерпретационные сайты и видео.

Для текстов интерпретаций полезны Google Books previews, материалы Ирины Грит, fengshui-bazi-qimen.ru, Joey Yap и Marina. Эти тексты нужно пересказывать самостоятельно и хранить отдельно от вычислительных правил.

Для вычислительного кода полезны открытые репозитории, но сравнивать необходимо не только итоговую карту, а каждый этап: солнечный термин, столпы, Yin/Yang Dun, номер Ju, земную тарелку, небесную тарелку, врата, звёзды, духов, 直符 и 直使. MrJelly нельзя использовать как прямое доказательство ошибки Aether в Zhi Run, поскольку его метод выбора Ju может отличаться.

## Источники, которые не следует использовать как подтверждённые

Сомнительные TXT/PDF-зеркала без лицензии, репозитории с массовыми нумерованными файлами, Scribd/Z-Library-копии без подтверждения правообладателя и страницы, где не указано происхождение текста. Их можно учитывать только как поисковый сигнал, но не скачивать и не использовать как источник содержания.
