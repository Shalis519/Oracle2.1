# Анализ specstruk2.pdf и текущего движка Ци Мэнь

## 1. Что добавляет файл

Файл вводит не только набор признаков структуры, но и второй уровень проверки. Сначала структура должна быть найдена в одном Дворце по сочетанию небесного ствола, земного ствола, звезды и Врат. Затем проверяется, может ли конкретный человек активировать структуру. Для этого учитываются назначение структуры, небесный ствол года рождения, Дворец структуры, Дворец Поддержки и порождающее взаимодействие элементов.

Практический вывод: обнаруженная комбинация и опубликованная пользователю пригодная структура не являются одним и тем же результатом. В пользовательский вывод должны попадать только структуры, прошедшие оба уровня.

## 2. Птица падает в гнездо

Комбинация в файле описана как Огонь Ян с Землёй Ян либо Огонь Ян с Деревом Ян; Дерево Ян определяется через таблицу Фу-то. Для активации человек находится в соответствующем секторе и работает. Временное окно начинается через 15 минут после начала двухчасовки и заканчивается за 15 минут до её окончания.

В файле есть два варианта правил по Вратам. Первый ограничивает структуру благоприятными Вратами, включая Отдых, Жизнь, Открытие, Пейзаж и иногда Тайник. Второй допускает неблагоприятные Врата при статичной активации, когда человек не движется в направлении Врат. Эти варианты нельзя объединять в одну автоматическую формулу без отдельного решения.

В текущем коде отдельного детектора «Птица падает в гнездо» не обнаружено. Значит, эту структуру нельзя добавлять автоматически, пока не будет выбрана одна из двух моделей Врат.

## 3. Дракон поворачивает голову

Файл описывает длительную активацию с вентилятором, работой лицом к Дракону или движением к нему. Для движения важны благоприятные Врата. В текущем коде отдельного детектора и модели активации этой структуры не обнаружено.

Для реализации потребуется формально определить, что именно является Драконом в карте: конкретный сектор или комбинация факторов. В PDF описан способ использования, но недостаточно однозначно задан алгоритм поиска сектора для автоматического расчёта.

## 4. Нефритовая Дева

Файл усиливает существующую формулу четырьмя положениями: Огонь Инь на Небесном стволе, Огонь Инь на Небесной и Земной тарелке, а также Главные Врата в том же Дворце. Сочетание с Главными Вратами является более сильным вариантом. Дополнительно упомянуты Врата Отдыха, Шесть Гармоний, Цветок романтики, запрет Северо-запада и Дворец Поддержки.

Текущий код уже имеет четыре варианта `jadeMaidenVariant` и ограничивает структуру часовыми картами. Врата ограничены пятью типами: Отдых, Открытие, Жизнь, Пейзаж и Тайник. В коде используется `mainGateStar(chart)` и сравнение Врат ячейки с `chart.zhiShiDoor`.

Однако следующие положения specstruk2.pdf пока не реализованы как отдельные фильтры или признаки: запрет Северо-запада для активации; Шесть Гармоний; Цветок романтики; Дворец Поддержки; связь с Дворцом Брака или Дворцом Семьи; различие силы основной и облегчённой версии. Это не означает, что их нужно немедленно добавлять: сначала необходимо решить, какие из них являются обязательными условиями публикации, а какие только усиливают результат.

## 5. Три Генерала

Новый файл не заменяет отдельную формулу Трёх Генералов из `generals.pdf`. Для Трёх Генералов остаются обязательными: небесное кольцо, один из стволов 乙/丙/丁, одна из звёзд 天辅/天心/天任, Врата Отдыха/Жизни/Открытия, отсутствие Фу Инь, Пустоты, Гэн, Могилы, запретных направлений Врат и контроля Врат над звездой.

Текущий детектор `detectThreeGenerals` применяет эти условия и публикует только разрешённые Врата. Персональный конфликт животного дня с животным года рождения применяется в публичном сканере `computeQimenStructures`.

Новый файл добавляет общий принцип связи человека со структурой через Дворец Поддержки и порождающее взаимодействие элементов. В текущей публикации Трёх Генералов этот новый персональный критерий пока не применяется. Его нельзя добавлять без согласования, поскольку это изменит уже утверждённую логику персонального фильтра.

## Вывод

Файл specstruk2.pdf следует использовать как расширенную спецификацию, а не как основание для немедленного изменения всех формул. Сначала нужно согласовать статус каждого нового положения: обязательное условие публикации, усилитель результата или инструкция ручной активации. Наиболее безопасный следующий шаг — отдельно утвердить расширение Нефритовой Девы правилами Главных Врат, Шести Гармоний, Цветка романтики и Дворца Поддержки, не смешивая их с формулой Трёх Генералов.
