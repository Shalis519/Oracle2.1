# Визуальный эталон infengi для карты Ци Мэнь

Дата просмотра: 20.08.2026.

Открытая страница infengi `/qm` показывает карту в виде квадратной сетки 3×3 с восемью направленными Дворцами и центральным Дворцом. В заголовке каждого периода выводятся Fu Tou, Драйвер, Главные Врата и Главная звезда. В ячейках визуально разделены слои: дух, Врата, ствол Небесной тарелки, звезда, ствол Земной тарелки и дополнительные обозначения.

Страница позволяет переключать карты года, месяца и дня, а ниже показывает 13 часовых периодов: ранняя Крыса, Бык, Тигр и так далее до поздней Крысы. Для каждой двухчасовки доступна отдельная карта.

В открытой версии infengi не обнаружено отдельного пользовательского экрана личной карты Ци Мэнь по дате рождения. Текст страницы сообщает о возможности построить личную карту Ба Цзы в полной версии, но это не является доказательством наличия личной карты Ци Мэнь. Поэтому в Aether Oracle визуал 3×3 можно реализовать по этому эталону, но алгоритм персональной карты рождения должен опираться на книгу Ци Мэнь и подтверждённые правила, а не копироваться из визуала infengi.

Рекомендуемая структура будущего экрана Aether Oracle:

1. Заголовок «Личная карта Ци Мэнь» и данные рождения.
2. Период построения: часовая карта на момент рождения.
3. Заголовок карты с четырьмя столпами, раскладом Инь/Ян, номером Цзюй, Fu Tou, Драйвером, Главными Вратами и Главной звездой.
4. Большая адаптивная сетка 3×3 с восемью направлениями, центром, иерархией слоёв и русскими названиями.
5. Блок «Личные показатели»: судьба по году, Дворец судьбы, НС дня, Дворец тела при подтверждении правила.
6. Отдельная панель для структур и персональных связей, включая Дворец Поддержки.

Текущая вкладка Aether Oracle уже строит часовые карты событий через `buildChart(date, hourBranch, lateZi)`, но отдельного API и UI для карты рождения пока нет.
