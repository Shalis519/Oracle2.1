# Сопоставление двух новых видео Марины с Aether Oracle

## Общий вывод

Эти два видео существенно полезнее предыдущих теоретических роликов. Первое показывает конкретный пример расклада Инь 7 для дня 丁酉 и часа 庚子. Второе объясняет последовательность постановки Земной тарелки для Ян/Инь Дунь и порядок небесных стволов.

## Подтверждённая последовательность

Из второго видео извлекается следующая схема:

1. По солнечному календарю Ся определить Инь Дунь или Ян Дунь и номер 局.
2. Поставить 戊 в дворец, соответствующий номеру 局.
3. Расставить стволы в порядке 戊, 己, 庚, 辛, 壬, 癸, 丁, 丙, 乙.
4. Для Ян Дунь идти по пути Ло Шу в прямом направлении.
5. Для Инь Дунь идти по пути Ло Шу в обратном направлении.

Это практически совпадает с текущей реализацией в `qimen/chart.ts`: массив `SEQ` содержит `[4, 5, 6, 7, 8, 9, 3, 2, 1]`, то есть 戊己庚辛壬癸丁丙乙, а направление выбирается через `ju.yin`. Поэтому оснований переписывать земную тарелку по этому видео нет.

## Практический пример первого видео

Первое видео показывает Инь 7, день 丁酉 и час 庚子. В примере присутствуют Земная и Небесная тарелки, Врата, Звёзды и Боги. В нём также явно названы Главная Звезда 天禽/Птица и Главные Врата 开门/Открытие. Это полезный контрольный пример для будущей сверки карты, но анализ не подтверждает все промежуточные индексы и не доказывает, что интервал часа 庚子 был получен по солнечному или резиновому времени.

## Что видео не закрывает

Не показаны точная формула выбора числа 局 для конкретной даты, алгоритм 旬首/符首 во всех случаях, правила Главных Врат, полноценный расчёт Главной Звезды и Джи Фу, а также солнечное/резиновое/совмещённое время, границы часа Крысы и переход даты.

## Важное ограничение

Планетарные соответствия стволов и авторские объяснения через Солнце, Юпитер и другие планеты следует считать интерпретацией, а не правилами алгоритма. Их нельзя переносить в код без отдельного подтверждения классическим источником.
