# Дворец судьбы DP / 命宫 в личной карте Ци Мэнь

## Наблюдение по эталонным скриншотам

Для данных: 05.02.1980, 16:01, Тараз.

- На сайте Захарова дворец судьбы обозначен внутри ячейки аббревиатурой **DP**.
- В Mingli тот же дворец выделен **зелёной рамкой**.
- На обоих скриншотах выделена верхняя левая ячейка сетки, то есть один и тот же дворец.
- В терминологии Ци Мэнь это соответствует личному дворцу судьбы/жизни, обычно `命宫` (Мин-гун).

## Временной режим

Пользователь сообщает, что совпадение с Mingli получается, когда в Mingli отключена опция «Местное солнечное время». Это важное наблюдение: для определения DP нельзя автоматически использовать истинное солнечное время только потому, что оно применяется в отдельных расчётах проекта. Режим времени для DP нужно подтвердить отдельно.

## Не смешивать обозначения

DP/命宫 — личный натальный дворец человека. Он не равен:

- `值符` (Цзи Фу), дворцу главной звезды текущего расклада;
- `值使` (Цзи Ши), дворцу главных Врат;
- дворцу поддержки, который рассчитывается отдельным сравнением элемента НС года с элементом дворца.

## Текущий статус Aether Oracle

Личная часовая карта уже выводится, но отдельного поля и визуальной отметки DP/命宫 пока нет. До подтверждения полного правила расчёта код менять не следует. После подтверждения нужно будет добавить личный идентификатор дворца в модель ответа API и выделять соответствующую ячейку подписью `DP` или русским обозначением «Дворец судьбы».
