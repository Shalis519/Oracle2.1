# Проверка мобильного отображения QMDJ — 22.08.2026

Локальный Vite preview стартовал на порту 22333. При открытии `/qimen` в sandbox-экспозиции карта не загрузилась: приложение остановилось на Vite runtime overlay с ошибкой Clerk `failed_to_load_clerk_js`, потому что локальный временный домен не входит в разрешённые домены Clerk.

Поэтому по этому предпросмотру нельзя делать вывод о финальном мобильном визуале карты. TypeScript и production-сборка frontend до этого прошли успешно. Для визуальной проверки нужно открыть опубликованный Render-домен или настроить разрешённый домен Clerk, затем проверить:

- квадратность сетки 3×3;
- отсутствие горизонтального скролла;
- отсутствие наложения китайских символов, русских названий и скрытых стволов;
- читаемость верхней/нижней/боковых подписей;
- рамки главных Врат и главной звезды;
- отдельную отметку «Пустота»;
- отметку «Дворец Судьбы».
