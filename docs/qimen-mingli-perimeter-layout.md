# Внешняя разметка карты Ци Мэнь

Внутренняя область карты остаётся квадратной и содержит девять одинаковых дворцов. Внешнее кольцо не входит в размеры дворцов.

В верхней части располагаются три подписи для дворцов Юго-востока, Юга и Юго-запада: сторона света, стихия и ветвь-животное. В нижней части располагаются Северо-восток, Север и Северо-запад с ветвями Бык, Крыса и Свинья. Слева и справа используются вертикальные подписи для промежуточных ветвей; они поворачиваются, как в Mingli.

| Позиция | Направление/стихия | Ветвь-животное |
|---|---|---|
| Верх слева | Юго-восток, Дерево | 巳, Змея |
| Верх центр | Юг, Огонь | 午, Лошадь |
| Верх справа | Юго-запад, Земля | 未, Коза |
| Слева сверху | Дерево | 辰, Дракон |
| Слева центр | Дерево | 卯, Кролик |
| Слева снизу | Дерево | 寅, Тигр |
| Справа сверху | Металл | 申, Обезьяна |
| Справа центр | Металл | 酉, Петух |
| Справа снизу | Металл | 戌, Собака |
| Низ слева | Северо-восток, Земля | 丑, Бык |
| Низ центр | Север, Вода | 子, Крыса |
| Низ справа | Северо-запад, Металл | 亥, Свинья |

Это визуальная справочная разметка внешнего кольца. Она не меняет расчёт часовой карты.
