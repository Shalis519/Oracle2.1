# Аудит GitHub-репозиториев, найденных по книгам Joey Yap

Дата: 21 августа 2026.

Проверены публичные метаданные GitHub API, лицензии, даты обновления, README и дерево имён файлов. Содержимое файлов-копий книг не извлекалось.

| Репозиторий | Наблюдения | Вывод |

У этих репозиториев нет подтверждённой связи с Joey Yap Research Group, издателем или авторами книг. Отсутствие лицензии само по себе не доказывает нарушение, но при наличии массовых нумерованных TXT-файлов, отсутствия описания и отсутствия источника правообладателя недостаточно оснований считать материалы разрешёнными.

## Репозиторий, не относящийся к книге

`erickovisck/TCC_COT` описан как учебный проект сайта для читателей. Совпадения с `men` и `.txt` относятся к файлам интерфейса и кредитам, а не к книге Joey Yap.

## Легальные технические альтернативы

`biblioverse/biblioteca`, `BookHeaven/BookHeaven.Server` и `oxdef/lib2opds` являются библиотечными приложениями и каталогизаторами, а не источниками защищённых книг. Их можно рассматривать только как программные инструменты.

Для алгоритмического анализа Ци Мэнь пригоднее открытые программные реализации `MrJelly/QiMenDunJia`, `deminzhang/qimen-go`, `oceanjustinlin/qimen` и `ChesterRa/mingpan`; они не заменяют книгу Joey Yap, но позволяют сравнивать расчётные этапы.

## Итог

Репозитории проверены в публичных пределах. Обход ограничений не выполнялся, содержимое подозрительных TXT-файлов не скачивалось и не анализировалось. По метаданным они не подходят как подтверждённые источники книги. Для Aether Oracle безопаснее использовать официальный Google Books preview, Amazon sample, библиотечный доступ и материалы, которые пользователь легально передаст для анализа.
