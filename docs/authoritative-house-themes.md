# Авторская таблица домов Aether Oracle

## Правило использования

Этот список является авторским базовым словарём жизненных тем для Oracle Studio. Он используется при заполнении профилей домов и грамматических форм. Символические соответствия «поле — планета» из файла «Символизм полей» используются как отдельный слой для рекомендаций, образов и дополнительных ассоциаций.

В расчётном слое дом и планета остаются самостоятельными сущностями. Символическое соответствие не заменяет номер дома, управителя, планету или фактическое положение карты.

## Приоритет источников

Для профилей домов приоритет имеет авторский список пользователя. Файл «Символизм полей» расширяет его образами, речевыми характеристиками, предметами, цветами, животными, камнями, телесными ассоциациями и нишами. Три переданные книги используются для поиска литературных формулировок, но не должны менять базовый перечень домов без отдельного согласования.

Источник: авторские данные пользователя и файл «Символизм полей».


## Авторские символические кластеры

Уточнение пользователя: соответствие означает не замену дома планетой или знаком, а общий символический кластер. Всё, что описано для 12-го дома, может использоваться и при описании Нептуна и Рыб; темы 11-го дома — также для Урана и Водолея; темы 10-го — для Сатурна и Козерога; темы 9-го — для Юпитера и Стрельца; темы 8-го — для Плутона и Скорпиона; темы 7-го — для Венеры и Весов; темы 6-го — для Меркурия и Девы; темы 5-го — для Солнца и Льва; темы 4-го — для Луны и Рака; темы 3-го — для Меркурия и Близнецов; темы 2-го — для Венеры и Тельца; темы 1-го — для Марса и Овна.

| Дом | Планета | Знак | Общий кластер |
|---:|---|---|---|
| 1 | Марс | Овен | Я, тело, личное проявление, способ действовать и заявлять о себе |
| 2 | Венера | Телец | Личные деньги, ресурсы, ценности, материальная опора |
| 3 | Меркурий | Близнецы | Речь, обучение, документы, транспорт, близкие связи |
| 4 | Луна | Рак | Дом, семья, род, недвижимость, внутренняя опора |

Этот кластер используется для обогащения семантики и литературных шаблонов: при описании планеты или знака можно брать соответствующие темы дома, а при описании дома — учитывать аналогичную планету и знак. Фактический расчёт карты при этом продолжает хранить дом, планету и знак раздельно.
