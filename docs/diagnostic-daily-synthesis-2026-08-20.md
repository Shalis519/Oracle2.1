# Диагностика исчезновения синтеза дня

На скриншоте пользователя страница `/dashboard` загружена, но вместо блока «Синтез дня» показано «Прогноз на сегодня пока недоступен».

Локальный frontend `artifacts/web/src/pages/dashboard.tsx` показывает карточку синтеза только при truthy-значении `forecast`; иначе отображает состояние unavailable. Запрос выполняется через `useGetTodayForecast()`.

Локальный API-маршрут `GET /forecast/today` вызывает `getOrComputeToday(...)` и возвращает 400 «Не удалось рассчитать прогноз», если результат отсутствует. `computeDailyForecast(...)` возвращает `null` только при некорректной дате рождения. Расчёт синтеза использует `natalChart`, транзиты и `futuristicGenerator`, а при отсутствии транзитов формирует обычный текст «Сегодня особенных астрологических событий не прогнозируется.»

При открытии production URL из песочницы активной пользовательской сессии нет; `/dashboard` перенаправляет на `/sign-in` Clerk. Поэтому личный запрос пользователя и серверный ответ пока не проверены напрямую.

Дата проверки: 20.08.2026.

Дополнительная проверка через доступный браузер также открыла `/sign-in`, а не авторизованный dashboard. Личная сессия пользователя не передалась, поэтому серверный статус `/forecast/today` и его response body остаются непроверенными.

После передачи управления авторизованный dashboard подтвердил состояние «Прогноз на сегодня пока недоступен». Диагностический запрос с текущим Clerk Bearer-токеном к `https://aether-oracle-api.onrender.com/api/forecast/today` вернул HTTP 500 и стандартную страницу `Internal Server Error`. Это не ошибка отсутствия профиля и не ошибка frontend-условия: API падает на сервере.

Панель Render в текущей сессии открывает страницу входа, поэтому stack trace Render пока недоступен.

После ручного Render-деплоя и обновления страницы 20.08.2026 dashboard по-прежнему показывает «Прогноз на сегодня пока недоступен». Авторизованная сессия сохраняется. В браузере ранее диагностический endpoint возвращал HTTP 500; требуется свежий ответ после коммита a801289.
