# Поиск книг Joey Yap через GitHub-каталоги

Дата проверки: 21 августа 2026.

## Что проверялось

Поиск выполнен через GitHub по запросам `free books library`, `ebook library`, `Qi Men Dun Jia Compendium`, ISBN `9789670794532`, а также `Joey Yap Qi Men`. Дополнительно проверены поисковые результаты по официальным материалам Joey Yap.

## Результат

GitHub действительно содержит репозитории библиотечного ПО, OPDS-каталогов и менеджеров электронных книг, например Biblioteca, BookHeaven и lib2opds. Однако это программные проекты для управления собственной библиотекой, а не легальные каталоги, где обязательно хранятся книги Joey Yap.

Поиск по названию и ISBN обнаружил несколько репозиториев с текстовыми файлами и упоминаниями электронных книг. По структуре имён и путей (`kata/topbook_Part377.txt`, `old/kata/livre_750.txt` и аналогичные файлы) они выглядят как файловые раздачи или зеркала сомнительного происхождения. Лицензии правообладателя на эти материалы не указаны. Такие файлы не клонировались, не скачивались и не использовались.

Официального GitHub-репозитория Joey Yap Research Group с бесплатным полным текстом Qi Men Dun Jia Compendium не найдено. В поисковой выдаче не обнаружены подтверждённые бесплатные полные версии других книг Joey Yap.

## Полезные открытые альтернативы

- Официальный [Google Books preview](https://books.google.com/books?id=XKZJDwAAQBAJ) с оглавлением и выбранными страницами.
- Официальный [Joey Yap Store](https://store.joeyyap.com/products/qi-men-dun-jia-compendium-second-edition) с описанием книги и перечнем глав.
- [Amazon Kindle sample](https://www.amazon.com/Men-Dun-Jia-Compendium-Second-ebook/dp/B07G9149FV).
- Открытые репозитории с реализациями Qi Men Dun Jia, которые не являются книгами, но могут пригодиться для алгоритмического сравнения: `MrJelly/QiMenDunJia`, `deminzhang/qimen-go`, `oceanjustinlin/qimen`, `ChesterRa/mingpan`.
- Поисковые ссылки библиотек через Google Books/WorldCat по ISBN `9789670794532` и `9670794536`.

## Вывод для Aether Oracle

GitHub-поиск не дал легального бесплатного полного текста книги Joey Yap. Он выявил полезную инфраструктуру и независимые программные реализации, но найденные файловые репозитории с копиями книг нельзя считать разрешёнными источниками. Для проекта безопасно использовать Google Books preview, официальные материалы Joey Yap и открытые QMDJ-репозитории с лицензиями, а не непроверенные PDF/TXT-раздачи.
