# Проверка видео о выборе дат для стрижки

## Основной вывод

Видео не содержит технических правил Ци Мэнь Дунь Цзя. Оно полностью посвящено выбору благоприятных дат для стрижки волос по тибетскому лунному календарю.

В ролике рассматривается сопоставление лунных суток с датами солнечного календаря и цели вроде денег, долголетия, привлекательности, ума и счастья.

## Что отсутствует

В видео нет Фань Инь, Фу Инь, взаимодействий небесных стволов, Небесной и Земной тарелок, Врат, Звёзд, Богов, Джи Фу, Главных Врат, годовой карты, Инь/Ян Дунь или систем солнечного/резинового времени.

## Решение для проекта

Материал не применим к `qimen/chart.ts`, `baziHours.ts` или интерпретациям Ци Мэнь. Его можно рассматривать только как отдельный источник по тибетскому лунному календарю, если такой модуль когда-либо понадобится.
