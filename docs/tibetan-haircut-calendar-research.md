# Исследование календаря стрижек по тибетской традиции

## Проверенный вывод

Видео `XtOzUr_JP6s` посвящено выбору дат стрижки по тибетскому лунному календарю. По сохранённому видеоразбору оно объясняет связь лунного дня с солнечной датой и смысл результата стрижки, но не показывает полный воспроизводимый алгоритм календарного вычисления.

## Что подтверждают открытые источники

Открытые материалы описывают таблицу результатов по номеру тибетского лунного дня. Например, 8-й день связывается с долголетием, 9-й с привлекательной энергией, 10-й с магнетизмом, 11-й с интеллектом, 26-й и 27-й со счастьем; ряд дней указан как неблагоприятный. Источник также предупреждает, что тибетские лунные даты нельзя просто считать от новолуния по григорианскому календарю: некоторые лунные дни пропускаются, а некоторые повторяются.

Rigpa уточняет, что календарь следует традиции Phugpa и рассчитывается Men-Tsee-Khang; каждый лунный день и день недели может иметь статус благоприятного, нейтрального или неблагоприятного для конкретных действий, включая стрижку.

## Минимальные данные для реализации

Чтобы построить рабочий модуль, нужны:

1. точная традиция/школа календаря, например Phugpa;
2. источник эфемерид или проверенный алгоритм тибетского календаря;
3. правила повторяющихся и пропускаемых лунных дней;
4. правила часового пояса, местного времени и границы тибетского дня;
5. таблица «номер лунного дня → результат стрижки» из согласованного первоисточника;
6. правила приоритета, если одновременно действуют лунный день, день недели, особый тибетский день или неблагоприятный период;
7. контрольные даты, сверенные с авторитетным календарём.

## Что можно реализовать уже сейчас

Можно сделать справочный data-driven модуль, который получает точную тибетскую лунную дату из внешнего/проверенного календарного слоя и возвращает утверждённый текст результата стрижки. Нельзя безопасно реализовать самостоятельный расчёт только по ролику, потому что видеоразбор не содержит полной формулы преобразования григорианской даты в тибетскую лунную дату и не фиксирует все исключения.
