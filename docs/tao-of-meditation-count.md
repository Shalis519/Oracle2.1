# Подсчёт практик в «Дао медитации» Стефена Волински

По извлечённому тексту предоставленного DOC-файла найдено **54 самостоятельных блока, начинающихся с «Медитация»**. Это подсчёт авторских обозначенных блоков, а не количество всех упоминаний слова.

Слово «медитация» встречается значительно чаще, поскольку входит в объяснения, повторные инструкции и описания процесса. Внутри некоторых из 54 блоков есть несколько шагов или вариантов практики. Поэтому число 75 может быть расширенным неофициальным подсчётом, если считать отдельные подупражнения, варианты и повторные техники, но как точное число самостоятельных авторски обозначенных медитаций по тексту оно не подтверждается.

Рабочий вывод: для каталога можно говорить «в книге описано более 50 медитативных упражнений», а не утверждать без оговорки «75 медитаций».
