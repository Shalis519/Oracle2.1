# Цветовая кодировка элементов Ци Мэнь

Для визуализации карты используются традиционные соответствия пяти стихий. Цвета применяются прежде всего к иероглифам элементов; русские подписи сохраняются в бирюзовом цвете для читаемости.

Цвет ствола определяется его стихией: 甲乙 — Дерево, 丙丁 — Огонь, 戊己 — Земля, 庚辛 — Металл, 壬癸 — Вода.
