# Рабочие выводы по книгам о транзитах

## Константин Дараган, «Транзиты: краткое руководство»

Книга предлагает читать транзит на трёх уровнях: психологическом, событийном и уровне причинно-следственных связей. Для множественных транзитов важна иерархия: медленные планеты задают основной длительный процесс, а быстрые планеты уточняют и активируют его. Это поддерживает текущую архитектуру «главный транзит + дополнительные», но дополнительные транзиты должны получать собственное описание, а не механически перечисляться.

Книга также подчёркивает необходимость связывать транзитную планету, принимающую натальную точку и дом, через который проходит транзит. Поэтому для каждого шаблона нужны отдельные данные планеты, аспекта, транзитного дома и натального дома.

## Лариса Назарова, «Искусство прогнозировать»

Книга рассматривает транзиты как возможные проявления, а не как гарантированные личные события. Формулировки прогноза должны учитывать потенциальность транзита и не превращать социальные планеты или быстрые аспекты в обязательные переживания человека.

Для дальнейшей работы необходимо извлекать из книги конкретные трактовки транзитных планет и домов, а затем размещать их в Oracle Studio. Если для конкретной связки нет проверенного фрагмента, шаблон не следует выдумывать.
