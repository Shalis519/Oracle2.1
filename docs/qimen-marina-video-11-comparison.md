# Сопоставление видео о небесных стволах с Aether Oracle

## Основной вывод

Видео является вводным анонсом о соответствии Небесных стволов объектам Солнечной системы. Оно не содержит алгоритмов построения карты Ци Мэнь Дунь Цзя.

## Содержание

Автор сопоставляет 甲 с Солнцем, 乙 с Меркурием, 丙 с Венерой, 壬 с Землёй, 庚 с Марсом, 戊 с Юпитером, 丁 с Сатурном, 己 с Ураном, 辛 с Нептуном и 癸 с Плутоном. Отдельно подчёркивается роль 戊 как важного ствола и «мерила» при построении карт.

## Что отсутствует

В видео нет правил Врат, сезонной силы, Фу Инь/Фань Инь, Инь/Ян Дунь, номера 局, 旬首/符首, постановки тарелок, Джи Фу, Главных Врат, систем времени или границ часа Крысы.

## Решение для проекта

Планетарные соответствия можно хранить как авторскую справочную модель для объяснений, но нельзя использовать их как формулы расчёта. Особенно нельзя менять постановку Земной тарелки или логику скрытого Цзя только на основании этого ролика. Практический материал автор обещает раскрывать в следующих видео.
