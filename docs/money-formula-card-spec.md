# Спецификация карточек денежной формулы

Источник всех литературных текстов: файл «Денежные дома — Илья». Тексты не редактируются и не дополняются автоматически. Пример Генри Форда не является обязательной карточкой и не включается в автоматический расчёт.

## Расчётные показатели

Для каждой натальной карты код определяет:

1. знак на куспиде II, V, VIII и XI домов;
2. управителя каждого из этих домов;
3. положение управителя в натальном доме;
4. планеты, находящиеся во II, V, VIII и XI домах;
5. активные комбинации, для которых в библиотеке существует утверждённая карточка.

## Порядок вывода

1. II дом и активные карточки его знака;
2. управитель II дома и его положение, если для него есть карточка;
3. планеты во II доме;
4. V дом, его управитель и планеты;
5. VIII дом, его управитель и планеты;
6. XI дом, его управитель и планеты;
7. итоговый блок только при наличии полного утверждённого набора исходных карточек, иначе без выдуманного синтеза.

## Карточки, явно присутствующие в источнике

| Ключ | Условие |
|---|---|
| `house-sign:2:capricorn` | II дом в Козероге |
| `planet-house:neptune:2` | Нептун во II доме |
| `house-sign:8:cancer` | VIII дом в Раке |
| `ruler-house:8:moon:4` | Управитель VIII дома Луна в IV доме; в источнике также указано, что Луна в Овне |
| `house:5` | Общий текст о V доме |
| `ruler-house:5:venus:9` | V домом управляет Венера, Венера в IX доме |
| `house:11` | Общий текст о XI доме |
| `ruler-house:11:pluto:11` | Управитель XI дома Плутон в XI доме; источник также содержит условие Скорпиона на XI доме |
| `summary:ilya-complete` | Итоговый текст образца только при полном наборе активных условий: II Козерог, VIII Рак, Венера — управитель V в IX доме |

## Правило отсутствия карточки

Если показатель есть в карте, но утверждённой карточки для него нет, код не придумывает трактовку и не подставляет текст от другой карты. Такой показатель либо выводится технически как незаполненный, либо отображается в служебной диагностике для дальнейшего заполнения библиотеки — по окончательному UI-решению денежного модуля.

## Разделение ответственности

Расчётный модуль определяет активные показатели карты. Библиотека карточек хранит утверждённые тексты и условия их применения. Сборщик результата сортирует активные карточки по домам и формирует разделы. Ни один из этих слоёв не должен самостоятельно создавать новую интерпретацию.
