Хочу изменить один важный момент в плане реализации.

Для меня Oracle Studio — это не административный просмотрщик базы данных, а основной рабочий инструмент проекта.

Поэтому Oracle Studio должна появиться практически сразу после создания структуры базы данных.

Мне необходим полноценный веб-интерфейс, через который я смогу без участия разработчика:

создавать новые сущности;
редактировать существующие сущности;
удалять сущности;
создавать и редактировать жизненные темы;
создавать связи между сущностями и темами;
заполнять и изменять смысловые профили;
искать и фильтровать информацию;
постепенно наполнять банк смыслов.
Все изменения должны сразу сохраняться в PostgreSQL.

Мне не должно требоваться изменять код проекта, запускать seed-скрипты или обращаться к разработчику для добавления новых данных.

Oracle Studio должна стать частью MVP и заменить текущий этап “Admin Explorer (read-only)”.

На первом этапе достаточно минимальной версии Oracle Studio:

список сущностей;
создание новой сущности;
редактирование сущности;
удаление сущности;
список жизненных тем;
редактирование жизненных тем;
редактирование смыслового профиля;
поиск и фильтрация.
На этом этапе визуализация графа, сложные инструменты и массовый импорт не требуются.

Прошу перестроить план так, чтобы Oracle Studio появилась сразу после создания структуры базы данных.
