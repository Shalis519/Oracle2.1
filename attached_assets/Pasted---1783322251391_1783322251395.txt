Хочу модернизировать чат (болталку), как в мессенджерах. 

Сейчас чат выглядит так:
- Поле ввода текста
- Отправка сообщений

Что нужно добавить:

## 1. Загрузка фото в чат

Функциональность:
- Кнопка "Прикрепить файл" (иконка скрепки или фотоаппарата) рядом с полем ввода
- Поддержка форматов: JPEG, PNG, GIF, WebP
- Максимальный размер: 10 МБ
- Фото отображается в чате как изображение под сообщением
- Автоматическое удаление через 24 часа (хранить временно на сервере)

Хранение:
- Временно на сервере в папке uploads/chat/
- Cron-задача: каждый час удалять файлы старше 24 часов

API для фото:
- POST /chat/upload — загрузка фото, возвращает URL
- При отправке сообщения добавляется поле imageUrl

## 2. Счетчик непрочитанных сообщений

Где отображать:
- В боковом меню рядом с пунктом "Болталка" (красный кружок с числом)
- В заголовке страницы чата

Логика:
- При получении нового сообщения, если чат не открыт → увеличить счетчик
- При открытии чата → сбросить счетчик в 0
- Обновление счетчика в реальном времени (polling или WebSocket)

API для счетчика:
- GET /chat/unread — количество непрочитанных для текущего пользователя
- POST /chat/read — отметить все как прочитанные

БД:
- Добавить поле is_read (boolean, default false) в таблицу messages

## 3. Звук уведомления

При получении нового сообщения (если чат НЕ открыт) — воспроизводить звук поющей чаши (тибетской чаши). Звук должен быть тихим и ненавязчивым.

Реализация:
- Добавить файл public/sounds/singing-bowl.mp3 (звук тибетской чаши, ~2-3 секунды)
- Воспроизводить при получении нового сообщения
- Громкость: 0.3 (30%)
- Обработка ошибок автоплея (если браузер блокирует)
- Если чат открыт — звук НЕ воспроизводится

## 4. Функция "Ответить на сообщение"

Как в мессенджерах: при нажатии на сообщение появляется кнопка "Ответить", и в поле ввода отображается цитата исходного сообщения, на которое отвечают.

Функциональность:
- При клике на сообщение появляется меню или кнопка "Ответить"
- В поле ввода появляется блок с цитатой исходного сообщения (текст + фото, если есть)
- Отправленное сообщение содержит ссылку на родительское сообщение (reply_to_id)
- В чате сообщение отображается с блоком цитаты над ним

API:
- При отправке добавить поле replyToId: number (опционально)
- При получении сообщения подтягивать данные родительского сообщения

БД:
- Добавить поле reply_to_id (integer, foreign key → messages.id) в таблицу messages

Отображение в чате:
- Сообщение-ответ отображается с блоком цитаты сверху
- Цитата содержит: имя автора, текст (обрезанный до 2-3 строк), фото (миниатюра)
- При клике на цитату — скролл к исходному сообщению

UI:
- Кнопка "Ответить" появляется при наведении на сообщение (или через долгий клик на мобильных)
- В поле ввода отображается цитата с крестиком для отмены
- После отправки ответа цитата исчезает из поля ввода

## 5. Автообновление

При закрытом чате:
- Счетчик обновляется каждые 30 секунд (polling)
- Если появляется новое сообщение → звук + обновление счетчика
- При открытии чата → счетчик сбрасывается, звук больше не играет

## 7. API (бэкенд)

### Загрузка фото:
POST /chat/upload
- multipart/form-data
- поле: image (файл)
- ограничение: 10 MB
- возврат: { url: "/uploads/chat/filename.jpg" }

### Счетчик непрочитанных:
GET /chat/unread
- возврат: { unread: 5 }

### Отметить как прочитанные:
POST /chat/read
- возврат: { success: true }

### Отправка сообщения (расширить):
POST /chat/message
- добавить поле imageUrl: string (опционально)
- добавить поле replyToId: number (опционально)
- создавать сообщение с is_read: false

### Получение сообщений (расширить):
GET /chat/messages
- возвращать сообщения с вложенным родительским сообщением (replyTo)

### Очистка фото:
Cron-задача (каждый час):
- Удалять файлы в uploads/chat/, где время создания > 24 часов
