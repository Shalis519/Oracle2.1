ТРЕБОВАНИЯ К ФУНКЦИОНАЛУ:

1. РЕГИСТРАЦИЯ И АВТОРИЗАЦИЯ:
   - Email + пароль.
   - Пользователь вводит: имя, дату рождения, время рождения, место рождения.
   - Загрузка фото (опционально).
   - В таблице users есть поля: photo_path, avatar_settings (JSON), avatar_type.

2. МАТРИЦА СУДЬБЫ:
   - Расчёт по дате рождения (22 аркана).
   - Все интерпретации из matrix_data.json.
   - На главном экране: аркан дня + рекомендации (травы, коктейль, аффирмация).

3. БАЦЗЫ:
   - Расчёт 4 столпов судьбы по дате рождения.
   - Определение Day Master.
   - Определение элемента дня.
   - Символические звезды: Цветок Персика, Путешествующая Лошадь, Благородный Человек.
   - Все интерпретации из bazi_data.json и bazi_stars.json.

4. ЗАПАДНАЯ АСТРОЛОГИЯ (AstroAsk API):
   - Пользователь вводит дату, время и место рождения в профиле.
   - Система отправляет запрос к AstroAsk API для получения натальной карты.
   - Ежедневно система запрашивает транзиты и прогрессии.
   - Определяет активные аспекты и сопоставляет с astrology_aspects.json.
   - Рассчитывает планетарные возвращения (Соляр, Лунар, Венусар, Меркуриар).
   - Если API-ключ не задан — система работает без астрологии.

5. ФЕН-ШУЙ / ЛЕТЯЩИЕ ЗВЁЗДЫ:
   - В профиле есть поле: направление изголовья кровати.
   - Система определяет, какая звезда в этом секторе в текущем году.
   - Выводит предупреждение, если звезда неблагоприятная (5, 2, 3, 7).

6. СИНТЕЗ (САМОЕ ВАЖНОЕ):
   - Синтез-движок собирает данные из всех активных систем.
   - Выдаёт единый прогноз на день с текстом.
   - Если есть конфликт (например, астрология говорит об опасности, а Бацзы — о движении), система предлагает компромиссное решение.
   - Учитывает историю обратной связи (если пользователь часто ставит "Не сбылось", система меняет приоритеты).

7. КОНТАКТЫ И ГЕНЕАЛОГИЧЕСКОЕ ДРЕВО:
   - Пользователь добавляет контакты: имя, дата рождения, дата смерти (опционально), телефон, email, тип родства.
   - Создаёт связи между контактами (родитель-ребенок, супруг, сиблинг).
   - Визуализация древа через библиотеку networkx + matplotlib.
   - Напоминалка о днях рождения (за 7 дней) на главном экране.

8. СНЫ И СОННИК:
   - Пользователь вводит текст сна.
   - Система ищет ключевые слова в dream_meanings.json и выводит толкование.
   - Сохраняет сон в БД.

9. ТРЕКЕР ПРИВЫЧЕК:
   - Водный баланс (цель 8 стаканов, кнопка "+1").
   - Счётчик шагов (цель 10000, ручной ввод).
   - Рекомендации из прогноза (коктейль, травы, аффирмация, ритуал) с чек-боксами.
   - Прогресс отображается в виде шкалы.

10. ОБРАТНАЯ СВЯЗЬ:
    - 3 кнопки под прогнозом: "Сбылось ✅", "Не сбылось ❌", "Частично ⚠️".
    - Поле для комментария.
    - Данные сохраняются в БД и влияют на будущие прогнозы.

11. КАРТА ПУТЕШЕСТВИЙ:
    - Страница /travel с интерактивной картой мира (amCharts).
    - Клик на страну → отметить как "Была" (зелёный) или "Хочу посетить" (фиолетовый).
    - Счётчики посещённых стран и вишлиста.
    - Данные хранятся в localStorage и могут быть отправлены на сервер.

12. ЗАГЛУШКИ:
    - Таро: страница с текстом "В разработке".
    - Аватар: загрузка фото + поле avatar_settings для будущего конструктора.
    - Ритуалы: пустой JSON-файл для будущего заполнения.

13. ИНТЕРФЕЙС:
    - Тёмная тема (цвета 2027 года): Deep Green (#1D4A3E) фон, Clay (#C27A5A) для карточек, Luminous Blue (#4A7CF7) для кнопок, Meadowland Green (#7BB661) для индикаторов, Peaceful Lilac (#B39BC8) для духовности, Pop Pink (#F28D9E) для эмоций.
    - Адаптивный дизайн (работает на телефоне).
    - Все шаблоны на русском языке.

14. ПОРТАТИВНОСТЬ И PWA:
    - Все настройки через .env.
    - Все пути — относительные.
    - При первом запуске создаётся папка /instance/ и база данных.
    - Файл .env.example с комментариями.
    - В папке /static/ созданы manifest.json и service-worker.js (заглушки для будущего PWA).

ДАННЫЕ ДЛЯ JSON (создать все файлы с полными данными):

1. matrix_data.json — полный файл со всеми 22 арканами (суть, плюсы/минусы, травы, масла, коктейли, аффирмации, здоровье, энергоканалы, питание).

2. bazi_data.json — интерпретации для 5 элементов (Дерево, Огонь, Земля, Металл, Вода) и 10 небесных стволов.

3. bazi_stars.json — данные для символических звёзд:
   - Цветок Персика: для каждой земной ветви — звезда, сектор, элемент, цвета, количество предметов.
   - Путешествующая Лошадь: для каждой земной ветви — животное-покровитель.
   - Благородный Человек: для каждой земной ветви — список животных-покровителей.

4. astrology_aspects.json — интерпретации для аспектов:
   - Транзитные аспекты (Марс_квадрат_Меркурий, Юпитер_трин_Солнце и т.д.).
   - Прогрессии (Луна_соединение_Асцендент и т.д.).
   - Дирекции (Солнце_квадрат_MC и т.д.).
   - Для каждого: описание, совет, уровень серьёзности (high/medium/low/positive).

5. dream_meanings.json — базовый сонник (100+ толкований): вода, рыба, огонь, дом, смерть, любовь, деньги, путешествие, и т.д.

6. fengshui_data.json — данные по летящим звёздам на 2026 год:
   - Для каждого сектора: номер звезды, название, влияние, рекомендация.

7. rituals.json — пустой файл (пользователь заполнит позже).

ВНЕШНИЕ API:

1. ASTROASK API (западная астрология):
   - Эндпоинты:
     - GET/POST /api/v1/western — натальная карта.
     - POST /api/v1/western/transits — транзиты.
     - POST /api/v1/western/progressions — прогрессии и дирекции.
     - POST /api/v1/western/solar-return — соляр.
   - Ключ хранится в .env: ASTRO_API_KEY.
   - Бесплатный тариф: 500 запросов/месяц.

2. AMCHARTS (карта путешествий):
   - Подключение через CDN.
   - Используется бесплатная библиотека.

АЛГОРИТМ СИНТЕЗА (как формируется прогноз):

1. Сбор данных:
   - Матрица Судьбы: аркан дня, травы, коктейль, аффирмация.
   - Бацзы: элемент дня, активации (Цветок Персика, Лошадь, Благородный Человек).
   - Астрология: транзиты, прогрессии, дирекции, планетарные возвращения.
   - Фен-шуй: сектор кровати, летящие звёзды.
   - Трекер привычек: вода, шаги, выполненные рекомендации.

2. Анализ конфликтов:
   - Если астрология даёт предупреждение (например, Марс квадрат Меркурий — проблемы в дороге) И Бацзы активирует Лошадь (движение), система объединяет их в одну рекомендацию.
   - Если системы не противоречат — система усиливает их эффект.

3. Формирование текста:
   - Синтез-движок генерирует текст, который включает все слои прогноза.
   - Текст адаптируется под пользователя (используется имя, история оценок).

4. Сохранение:
   - Прогноз сохраняется в таблицу daily_forecasts.
   - Пользователь может оценить его через обратную связь.
